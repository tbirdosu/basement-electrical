⚠ Critical Rule — No Mixing Never mix wire gauges on the same circuit. 12-gauge wire on a 15A breaker is wasteful. 14-gauge wire on a 20A breaker is a fire hazard — the breaker won't trip before the wire overheats.

Project Checklist

Tap items to mark complete. Progress saves while page is open.

Planning & Permits

  • Pull electrical permit from Columbus Building & Zoning Services (614-645-7433)
  • Convert slots 21 & 22 (Lighting/Lighting) to QOT1515 tandem — frees 1 slot
  • Convert slots 19 & 20 (Dining Lighting/Whole House Vent) to QOT1515 tandem — frees 1 slot
  • Move Radon Fan off slot 28 onto Circuit 2 general outlet — frees slot 28
  • If 4th slot needed: convert slots 29 & 30 (Dishwasher/Garage Door) to QOT1515
  • Verify amp rating on existing basement lighting wire (confirm it's 12/2 before upgrading to 20A breaker)
  • Plan outlet layout — mark every wall section 2 ft+ wide that needs an outlet

Materials to Buy

  • Square D QO120DFC breakers (yellow/black packaging) — buy 4 for new basement circuits
  • Square D QOT1515 tandem breakers — buy 2 (slots 21/22 and 19/20), 3rd if needed for 29/30
  • Square D QOT2020DFC — optional if combining two basement circuits into one slot
  • 12/2 NM-B (Romex SIMpull) — yellow jacket
  • 12/3 NM-B — for all switch boxes and 3-way switch runs
  • Steel nail plates — for any hole within 1¼" of stud face
  • ⅞" paddle bit (and 1" for multi-wire runs)
  • Electrical boxes — outlet and switch boxes
  • GFCI/AFCI receptacles (if not using breaker-level protection for all outlets)
  • Panel extender ring (if alcove approach doesn't fully solve panel depth issue)

Rough-In Work

  • Frame alcove around panel — minimum 30" wide, maintain 3 ft clearance in front
  • Mark outlet box heights — 12" from finished floor (consistent throughout)
  • Mark switch box heights — 48" from finished floor
  • Drill ⅞" holes through studs at 12" height
  • Install nail plates wherever holes are within 1¼" of stud face
  • Run 12/2 for all outlet circuits (Circuits 1, 2, 3)
  • Run 12/2 for lighting circuit (Circuit 4)
  • Run 12/3 to all switch boxes
  • Run 12/3 between 3-way switch pairs
  • Install tandem breakers in panel to free up slots
  • Install new QO120DFC breakers for basement circuits

Inspections & Finish

  • Schedule rough-in inspection BEFORE hanging drywall
  • Pass rough-in inspection
  • Hang drywall
  • Install outlets and switches
  • Update panel directory label with new circuit names
  • Final inspection
